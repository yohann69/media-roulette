# Media Roulette

A free, open-source party game: everyone's phone picks random photos and videos from their library, and players race to guess whose picture is on screen.

## Project layout

- `frontend/`: the mobile app (Expo SDK 58, React Native, expo-router)
- `backend/`: the game server (Node.js, Express, Socket.IO)

## Running locally

Requirements: Node.js 22 or 24 (even-numbered releases), Xcode for iOS and/or Android Studio for Android.

```bash
cd backend
npm install
npm run dev          # listens on port 6969 (override with PORT)
```

```bash
cd frontend
npm install
EXPO_PUBLIC_SERVER_URL=http://localhost:6969 npx expo run:ios   # or run:android
```

`EXPO_PUBLIC_SERVER_URL` points the app at your own server. Without it, the app uses the public game server.

The native `ios/` and `android/` folders are generated by `npx expo prebuild` and are not committed.

## How media is handled

- Photos are resized on the phone (longest side 1440 px) and re-encoded, which strips location and camera metadata.
- Videos are cut to a short clip and re-encoded at 720p on the phone.
- The server stores media only for the duration of a game, serves it only to players of the same room, and deletes it when the game ends, when a player leaves, or after 15 minutes of inactivity.
